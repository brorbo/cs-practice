git show подробно расписывает последний (или конкретно указанный) коммит, в то время как git diff показывает только РАЗНИЦУ между еще не закоммиченными настоящими изменениями и последним коммитом.
А git log выводит целую сводку информации по всем (или нет, в зависимости от параметров) сделанным уже комитам.
log -S ищет изменение количества вхождений конкретной строки по коммитам (в моем случае по строке def вхождений никогда не было вовсе)
git blame выводит автора каждой строчки в конкретном указанном файле

git restore возвращает файл в состояние последнего коммита, а параметр source возвращает изменения из указанного коммита, а не последнего. --source=HEAD~2 вернет состояние файлы из ПОЗАпрошлого коммита.
