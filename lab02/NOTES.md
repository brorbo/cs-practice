рабочая папка - папка со всеми файлами проекта.

индекс - место подготовки к сохранению изменений в коммит.

коммит - сохранение изменений всех файлов в индексе в память программы. будет выгружен при следующем пуше на сервер.



git - это сама локальная программа, запомнинающая, сохраняющая и отправляющая на сервер изменения в файлах

GitHub - это сервис, который работает с файлами git и отображает всю отправленную информацию на сервер
